User guide · v0.2.0 release

대화를 읽고, 결정하고,
실행하는 하나의 업무 공간

글로벌 레일의 오늘부터 통합 알림함, 채널, 내 업무, 실제 SSE AI와 승인 센터까지 Moyro Flow를 따라 설명합니다.

Task·Decision·RAG처럼 아직 API가 없는 기능은 화면에서도 준비 상태로 구분합니다.
이 페이지에서로그인과 버전오늘·알림함채널·컨텍스트내 업무검색·AI승인 센터개인 설정모바일문제 해결

1. 로그인과 서비스 버전

관리자가 안내한 내부 moyro 주소를 엽니다. 이메일 또는 사용자명과 비밀번호로 로그인합니다. 관리자가 Keycloak OIDC를 활성화했다면 로그인 화면에 SSO 진입점도 표시됩니다.

로컬 회원가입이 닫힌 조직에서는 관리자가 발급한 초대 링크를 여세요. 링크에 지정된 워크스페이스를 확인한 뒤 12–72바이트 비밀번호로 계정을 만들 수 있습니다. 만료·폐기·사용 횟수 소진 링크는 가입에 사용할 수 없습니다.

로그인 뒤에는 오른쪽 위의 계정 메뉴 열기 버튼을 선택합니다. 프로필 컨텍스트 메뉴에서도 동일한 버전을 확인할 수 있습니다. 오류를 문의할 때 버전과 발생 시각을 함께 전달하세요.

2. 글로벌 레일, 오늘과 통합 알림함

로그인하면 오늘이 업무 시작점으로 열립니다. 데스크톱 글로벌 레일은 오늘, 알림함, 대화, 내 업무, 검색, 승인과 권한이 있을 때 AI를 연결합니다. 오늘 화면은 서버에 저장된 채널별 unread·mention counter와 저장 메시지, 예약 메시지, 리마인더, 승인 요청을 집계하며 일부 API가 실패하면 해당 영역을 0으로 성공 처리하지 않고 경고합니다.

통합 알림함의 대화 탭은 개별 알림 feed가 아니라 채널별 unread·mention counter입니다. 채널 전체 읽음은 그 채널의 현재 메시지 전체에 적용됩니다. 개별 항목의 읽음·나중에·완료는 v0.2.0에 영속 API가 없어 제공하지 않습니다.

승인과 리마인더 탭은 각각 실제 승인 요청 및 메시지 리마인더 API를 사용합니다. 승인 검토 목록은 클라이언트가 전역 권한을 추정하지 않고 서버가 team·resource scope로 허용한 항목만 표시합니다.

3. 팀, 채널과 통합 컨텍스트

대화에서 팀과 채널을 선택하면 URL이 해당 위치로 바뀌며 새로고침해도 같은 채널이 복원됩니다. 공개·비공개 채널과 DM·그룹 메시지에서 게시, 답글, 파일, 반응, 수정, 삭제와 저장을 사용합니다.

오른쪽 컨텍스트 패널은 스레드·요약·파일·정보 탭을 제공합니다. 요약은 사용자가 버튼을 누를 때 현재 브라우저에 로드된 최근 메시지만 실제 SSE AI에 전송하고 입력으로 제공한 메시지 목록을 함께 보여줍니다. 이는 조직 전체 RAG 검색이나 모든 문장의 citation 보장이 아닙니다. 파일 탭도 현재 로드된 메시지의 첨부만 집계합니다.

4. 저장·예약·리마인더를 모은 내 업무

내 업무는 세 가지 실제 개인 데이터 탭을 제공합니다. 저장 탭에서는 메시지 저장을 해제하고, 예약 탭에서는 발송 전 pending·retry 항목을 취소하며, 리마인더 탭에서는 원문과 알림 시각을 확인하고 취소합니다. 별도 “즉시 전송” API나 Task·Decision 영속 모델은 제공하지 않습니다.

저장 메시지·리마인더·통합 검색·오늘 AI 브리핑의 원문 링크는 대상 post ID를 채널 작업 공간에 전달합니다. 현재 페이지에 그 메시지가 없으면 서버의 접근 검사를 거쳐 정확한 게시물만 추가로 불러온 뒤 해당 행으로 스크롤하고 키보드 포커스를 옮깁니다. 삭제됐거나 접근할 수 없는 메시지는 비슷한 최근 메시지로 대체하지 않고 오류를 표시합니다.

5. 통합 검색과 실제 SSE AI

통합 검색에서 가입한 팀을 선택하고 검색어를 입력하면 해당 팀의 PostgreSQL 메시지 검색 API가 결과와 전체 건수를 반환합니다. 작성자와 채널을 실제 API로 보강하지만 벡터·자연어 RAG, 파일 본문 또는 OCR 검색으로 표시하지 않습니다.

AI 도우미는 use_ai 권한과 개인 AI 설정을 확인한 뒤 입력한 대화만 OpenAI 호환 공급자에 SSE로 전송합니다. 응답 중지와 부분 응답 보존을 지원하지만 대화는 현재 브라우저 화면에만 있고 서버 이력, 자동 채널 검색, citation 또는 후속 작업 실행은 없습니다.

6. 승인 센터

승인 센터는 내 요청과 검토 대기를 분리합니다. 승인 정책이 비활성이어도 과거 이력을 확인할 수 있도록 진입점은 유지되며, 새 MCP 보호 작업은 활성 정책에 해당할 때만 요청을 만듭니다.

현재 응답에는 계산된 위험도, 외부 시스템 변경 전후 Diff나 검토자별 상세 타임라인이 없으므로 화면도 이를 추정하지 않습니다.

7. 개인 설정과 키

프로필 메뉴의 개인 설정에는 프로필, 화면, 알림, 세션, 개인 키와 AI 개인화가 있습니다. 사이트 URL, Keycloak과 AI 공급자처럼 조직 전체에 영향을 주는 값은 관리자 영역에 있습니다.

개인 키 화면에서 관리자가 허용한 scope와 수명 안에서 API·MCP 키를 발급합니다. Secret은 생성 또는 회전 응답에서 한 번만 표시되므로 안전한 credential 저장소로 바로 옮기세요.

활성 web plugin은 별도 개인 설정 section을 등록할 수 있습니다. 예를 들어 검증된 EchoSummary bundle은 plugin-owned preference를 Moyro 개인 설정 안에 표시하고 저장합니다. 플러그인을 비활성화하거나 교체하면 이전 bundle의 setting contribution은 제거되며, 이 동작이 Mattermost의 전체 개인 설정 registry 호환을 뜻하지는 않습니다.

8. 모바일 Flow

430×932 화면에서는 오늘·대화·알림함·검색을 하단 탐색으로 열고, 내 업무·승인·AI·설정은 더보기에서 이동합니다. 각 화면은 데스크톱 패널을 단순 축소하지 않고 한 열로 배치하며 E2E에서 가로 overflow가 없는지 확인합니다.

9. 문제가 생겼을 때

  • 현재 URL을 새로고침해도 같은 메뉴가 열리는지 확인합니다.
  • 연결 오류는 관리자에게 내부 네트워크와 /healthz 확인을 요청합니다.
  • 채널이나 파일 접근 오류는 해당 채널 멤버십을 확인합니다.
  • SSO 진입점이 없으면 관리자가 Keycloak을 활성화했는지 확인합니다.
  • 문의 시 서비스 버전, 발생 시각, 현재 URL과 수행한 작업을 전달합니다.
