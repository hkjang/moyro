# moyro 브랜드 자산

`moyro` 마크는 하나의 끊기지 않는 선으로 소문자 `m`을 그립니다. 양쪽 봉우리는 사람과 팀의 연결, 중앙 매듭과 민트색 점은 검토·승인 지점, 이어지는 선은 예측 가능한 업무 흐름을 뜻합니다. 단순한 실루엣과 굵은 획을 사용해 16px 파비콘부터 큰 홍보 화면까지 같은 인상을 유지합니다.

- 원본 로고 마크: `moyro-mark.svg`
- 가로형 로고: `moyro-wordmark.svg`
- 소셜 공유 이미지: `moyro-social-card.png` (1200×630)
- 파생 앱 아이콘: `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `maskable-icon-512.png`, `favicon.ico`

로고 주변에는 마크 높이의 25% 이상 여백을 두고, 비율을 변형하거나 글자 `M`을 덧씌우지 않습니다. 기본 브랜드 색상은 Blue `#315FEA`, Violet `#6849D8`, approval accent `#72F0C9`, Ink `#15203B`입니다.
